# GasWipeLab v4.1 — ワイピング条件 事前設定ツール

溶融亜鉛めっきライン（CGL）のガスワイピングについて、**実機を動かす前に操業条件を決める**ための
ブラウザアプリです。サーバ不要・オフライン動作（Pyodide で Python をブラウザ内実行）。

v4.0 で、実機プロコン **6か月・14,390件**（GI 7,076 / GL 7,314）から学習した予測モデルを搭載しました。

## 2つのモード

| モード | 使うとき | 予測の根拠 |
|---|---|---|
| **実機モード**（既定） | GI/GL の実機条件を決めるとき。通常はこちら | 実機実績から学習した勾配ブースティングモデル |
| **理論モード** | 実績に無い条件（ガス種・ノズルすき間の変更など）を検討するとき | 文献ベースの1次元物理モデル（v2.2から不変） |

### 実機モードのタブ

| タブ | 入力 | 出力 |
|---|---|---|
| **使い方** | — | アプリの目的・3ステップの手順・用語・結果の読み方（初回はここが開きます） |
| **条件設計**（主機能） | ① 何を作るか ② 目標の付着量 ③ 先に決まっている条件 | **必要なYノズル位置・圧力・流量・速度**（操業条件一式） |
| **装置画面** | 条件設計で入れた条件 | 実機のYG装置監視画面と同じ並びで表示。CF／CG／**両面合計CH**、診断値、応答カーブ |
| **条件比較** | 変更前と変更後 | 予測差分、変えた項目、共線性の警告 |

入力はすべて**スライダー**です（スマホで数値をキーボード入力しなくてよいように）。
目標や条件のスライダーから指を離すと、答えが自動で計算し直されます
（画面は勝手にスクロールしません）。
スライダーの可動範囲は実績データの範囲、目盛の説明には実績中央値とよく使う範囲（P10〜P90）を表示します。

### 変更提案の優先順位

`Yノズル位置` → `通板速度` → `ノズル圧力` の順に、**1項目だけ**を動かして目標に届く値を探します。
実績データ上、付着量に最も効くのはYノズル位置（付着量記号内相関 GI +0.42 / GL +0.35）で、
圧力はほぼ固定運用（GI 35〜36 kPa、GL 9.8〜11.9 kPa）のため最後に回しています。

**製品板厚・製品板幅・付着量記号・ラインは提案しません**（製品仕様・設備仕様のため）。

ちょうど届かない場合は、いちばん近づく条件を「近似」として提示します。
探索範囲は常に**ライン・付着量記号別の実績 P01〜P99 の内側**に限定しています。

## 精度

ホールドアウト（2026-06以降）での報告値。**両面合計 CH** に対する平均絶対誤差。

| ライン | CF | CG | CH（両面合計） | P90絶対誤差 | ±10 g/m²以内 |
|---|---:|---:|---:|---:|---:|
| GI | 3.73 | 3.53 | **6.62** | 13.20 | 82.0% |
| GL | 1.61 | 1.68 | **2.54** | 5.45 | 95.4% |

参考: 物理モデル単体の同条件 MAE は GI 約12.2 / GL 約6.16 g/m²。

## 装置画面（v4.1で追加）

実機のYG装置監視画面と同じ並びで、条件と予測を確認できます。値はすべて
**ProCデータと予測モデルから再現**したもので、実機から直接読んでいるわけではありません。

各値には出所を必ず添えます。

| バッジ | 意味 |
|---|---|
| `ProC` | 実績データの列から取得 |
| `予測` | 実機モデルの出力 |
| `導出` | ProC値から算術的に計算（平均とWS-DS差からWS/DS側を復元） |
| `未取得` | ProCに該当列が無く再現できない |
| `未確認` | 実機画面との対応が未確定。同義扱いしていない |

**ProCに存在しない項目**（ワイピング圧力・Yコンプレッサー吐出圧力・放風弁MV・
No.3Y機周波数・サポートロール回転・制御モード11種・指令No./コイルNo.）は、
枠だけ表示して「未取得」とし、推測値は入れていません。診断値も同様に、
計算に必要な値が無い項目は0で埋めず「未取得」と表示します。

制御モードはProCに記録がないため全て `UNKNOWN` です。バッフルテスト・
ノズルクイックオープン・ノズル清掃中はアプリ側で検知できないため、
これらの作業中は結果を使わないでください。

## 重要な用語と注意

- **CH は両面合計**（表面3点平均＋裏面3点平均）。片面平均ではありません。
  付着量記号はこのCHに対応します（例: AZ150 → 実績中央値 161、Z08 → 94 g/m²）。
- **Yノズル位置は設備Y座標**で、鋼帯表面からの絶対距離ではありません。数値が大きいほど鋼帯から遠い側です。
- **ノズル吹込流量**は表裏合計の実測流量（Nm³/h・暫定定義）。圧力と強く連動（GI r=0.977 / GL r=0.933）するため、
  圧力を変えると実績の関係にそって流量も追従させています。
- **付着量記号305は対象外**。ラインスタート時のウォーマーコイルで製品ではないため、選択できません。
- **GLに理論モードは使えません**。浴温が約600℃のガルバリウムで、物理モデルが前提とする溶融亜鉛
  （420〜500℃）の物性域から外れます。
- 実績件数が少ない付着量記号（20件未満）では警告を出します。予測も操業範囲も信頼度が下がります。
- 実機モデルは**過去実績の統計的補間**です。圧力・流量・Yノズル位置を独立に動かしたときの
  因果効果を保証するものではありません。

## 実行方法

静的サイトです。ビルド不要。

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます（`file://` では fetch が失敗するため不可）。
初回のみ Pyodide と実機モデル（約1.9MB）のダウンロードに数十秒かかります。2回目以降はキャッシュされます。

## ファイル構成

```
index.html                      UI（単一ファイル）
sw.js / manifest.json / icons/  PWA
models/                         実機モデル（v4.0で追加・計約1.9MB）
  manifest.json                 モデル定義・特徴量順序・GL基準値
  reference.json                実績レンジ・記号別統計・カテゴリ選択肢・圧力-流量関係
  GI_CF/CG/CH.json              GIモデル（直接回帰）
  GL_CF/CG/CH.json              GLモデル（記号別中央値＋残差）
python/gaswipelab/
  hmi/                          実機YG装置監視画面の再現（v4.1で追加）
    screen.py                   条件＋予測を画面の並びへ組み替える
    diagnostics.py              診断値10種（未取得はNone）
    control_modes.py            制御モード11種の状態
  ml/                           実機モデル推論（v4.0で追加）
    cityhash.py                 CatBoostのカテゴリ特徴ハッシュ
    catboost_runtime.py         純Pythonの推論器（CTR対応）
    predictor.py                GI/GLルーティング・GL基準値加算
    ood.py                      実績範囲の判定（範囲内／要注意／範囲外）
  models/                       物理モデル（v2.2から変更なし）
  services/
    analysis_service.py         物理モデルの解析パイプライン（変更なし）
    design_service.py           物理モデルの条件設計（変更なし）
    machine_design_service.py   実機モデルの条件設計・逆算（v4.0で追加）
    calibration_service.py      実績校正（変更なし）
```

開発用の変換スクリプトはリポジトリの `tools/`、回帰テストは `tests/` にあります。

```bash
python tests/test_ml_runtime.py        # ゴールデン30件・本家CatBoostとのパリティ・性能回帰
python tests/test_physics_unchanged.py # 物理モデルの非破壊確認
python tests/test_hmi_screen.py        # 装置画面の受入条件（数値整合・未取得の扱い）
```

## 注意

本ツールの結果は実機保証値ではありません。事前設定・条件検討の目安として使用し、
実機適用前には必ず検証を行ってください。実機モデルは約6か月分のデータで学習しており、
季節変動・設備改造後については未検証です。
