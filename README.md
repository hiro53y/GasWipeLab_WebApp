# GasWipeLab v4.4.7 — ワイピング条件 事前設定ツール

溶融亜鉛めっきライン（CGL）のガスワイピングについて、**実機を動かす前に操業条件を決める**ための
ブラウザアプリです。サーバ不要・オフライン動作（Pyodide で Python をブラウザ内実行）。

v4.0 で、実機の操業実績 **6か月・14,390件**（GI 7,076 / GL 7,314）から学習した予測モデルを搭載しました。

## 2つのモード

| モード | 使うとき | 予測の根拠 |
|---|---|---|
| **実績モデル**（既定） | GI/GL の実機条件を決めるとき。通常はこちら | 実機実績から学習した勾配ブースティングモデル |
| **理論モデル** | 実績に無い条件（ガス種・ノズルすき間の変更など）を検討するとき | 文献ベースの1次元物理モデル（v2.2から不変） |

### 実績モデルのタブ

| タブ | 入力 | 出力 |
|---|---|---|
| **使い方** | — | 目的・3ステップの手順・**画面ごとの詳細説明（9画面）**・何がどれだけ効くか・ワイピングの一般知見・計算のしくみ |
| **条件設計**（主機能） | ① 何を作るか ② 目標の付着量 ③ 先に決まっている条件 | **必要なYノズル位置・圧力・流量・速度**（操業条件一式） |
| **装置画面** | 条件設計で入れた条件 | 実機のYG装置監視画面と同じ並びで表示。CF／CG／**両面合計CH**、診断値、応答カーブ |
| **条件比較** | 基準からの変更 | 「もし〜したら」の検証。**モデルがその差を判別できるか**まで判定 |
| **モデル比較** | 条件設計で選んだ条件 | 実績モデルと理論モデルの答えを並べる（理論モデル側のメニューからも開けます） |

**起動時はいつでも「実績モデル ＞ 条件設計」から始まります**（v4.4）。
前回どのタブを開いていたかは覚えません。ライン・付着量記号・目標値は前回の値を復元します。

手順3「先に決まっている条件」は **通板速度・ポット温度・2JC進入板温** です。
板厚・板幅は手順1で入れるため重複させていません。

入力は**スライダーと数値入力欄のどちらでも**操作できます。両者は連動するので、
スマホでは指でバーを動かし、PCでは数値を直接打つ、といった使い分けができます。
数値欄は上下矢印に加えて**左右矢印でも1目盛ずつ増減**します。
製品板厚・製品板幅には **−/＋ のスピンボタン**と、よく使う寸法の**ワンタッチボタン**を付けています。

| 項目 | ボタン |
|---|---|
| 製品板厚 [mm] | 0.27 / 0.40 / 0.50 / 0.60 / 0.80 / 1.0 / 1.2 / 1.6 / 2.3 / 3.2 |
| 製品板幅 [mm] | 610 / 762 / 914 / 1000 / 1219 / 1350 |

押すとその値が入り、答えも計算し直します。いま選ばれている値のボタンは色が付きます。
目標や条件を変えると答えは自動で計算し直されます（画面は勝手にスクロールしません）。
スライダーの可動範囲は設備仕様の範囲、目盛の説明には実績中央値とよく使う範囲（P10〜P90）を表示します。

製品板厚・製品板幅の初期値は、ライン・付着量記号によらず **0.40 mm / 1219 mm** です
（記号を変えるたびにサイズが動くと比較しにくいため固定しています）。

### 板厚・板幅を変えると通板速度も入れ替わる（v4.4で追加）

板厚は通板速度と強く連動しています（実績の相関 **GI −0.863 / GL −0.688**、板幅は GI −0.146 / GL −0.416）。
そのため手順1で板厚・板幅を変えると、**そのサイズに近い実績の中央値**を手順3の通板速度へ入れます。

| 速度の決め方 | GI | GL |
|---|---:|---:|
| 付着量記号の中央値（v4.3まで） | 18.27 | 17.06 |
| **板厚×板幅の実績（v4.4）** | **8.21** | **6.84** |

5分割交差検証での平均絶対誤差 [m/min]。記号ごとに表を分けても改善しないため（GI 7.02 ≒ 7.07 /
GL 7.31 は悪化）、**ライン単位**の表にしています。
帯の境界には画面のプリセット値（板厚 0.27〜3.2 / 板幅 610〜1350）を必ず入れています
（分位点だけで切ると厚物が [1.6, 3.2] mm の1帯に潰れ、3.2 mm のコイルにも 1.6 mm 相当の速度が出ていました）。

薄物側は非単調です（GI で 0.27 mm 115 → 0.40 mm 120 m/min）。板幅1150〜1350帯では
0.25〜0.80 mm の速度がどれも 120〜135 でほぼ横ばい（ラインの上限に張り付いている）という
実データの性質で、**平滑化や単調化はしていません**。

- 手順3に「板厚 ○〜○ mm × 板幅 ○〜○ mm の実績 **n 件**の中央値」と、使った帯と件数を出します
- **1クリックで直前の速度に戻せます。** 生産計画で速度が決まっている場合はそのまま上書きしてください
- 実績の外側のサイズでは**外挿せず**、端の帯の実績値を出して「実績の外側です」と表示します
- 起動時の初期速度も、固定サイズ 0.40 mm × 1219 mm の実績から決めます
  （v4.3 までは記号別中央値で、固定サイズと噛み合っていませんでした。
  例：GI 記号「122」の速度中央値 57.0 m/min に対し、0.40 mm × 1219 mm の実績中央値は 125.0 m/min）

**これは初期値だけの変更です。** 予測モデルの入力項目・特徴量・重みは一切変えていません。

### 変更提案の優先順位

`Yノズル位置` → `通板速度` → `ノズル圧力` の順に、**1項目だけ**を動かして目標に届く値を探します。

**この順番は操業上の取り決めで、モデルが決めた優先順位ではありません。**
実績データから言えるのは「各項目が実績のばらつきをどれだけ説明するか」までです
（Yノズル位置がもっともよく説明する。付着量記号内相関 GI +0.42 / GL +0.35）。
圧力・流量・Yノズル位置は実機で連動して動かされてきたため（圧力と流量の相関 GI r=0.977）、
1項目だけ動かしたときの効果を実績データから切り分けることはできません。
圧力を最後に回しているのは、ほぼ固定運用（GI 35〜36 kPa、GL 9.8〜11.9 kPa）だからです。

**製品板厚・製品板幅・付着量記号・ラインは提案しません**（製品仕様・設備仕様のため）。

ちょうど届かない場合は、いちばん近づく条件を「近似」として提示します。
探索範囲は常に**ライン・付着量記号別の実績 P01〜P99 の内側**に限定しています。

## 精度

**画面に出しているのは時系列検証の値**です。月ごとに「その月より前だけで学習して、
その月のコイルを当てる」を繰り返した結果で、未知のコイルに対して期待できる誤差です。

| ライン | CH平均絶対誤差 | 最悪月 | \|誤差\|の90%点 | ±10 g/m²以内 |
|---|---:|---:|---:|---:|
| GI | **6.7** | 6.9 | 15.0 | 80.9% |
| GL | **3.2** | 4.2 | 7.0 | 94.3% |

同じデータを違う切り方で測ると値が変わります。取り違えないよう3つ並べます。

| 測り方 | GI | GL | 意味 |
|---|---:|---:|---|
| 時系列検証（**画面表示**） | 6.72 | 3.20 | 未知のコイルに対する実力 |
| 引継ぎ報告値（2026-06で評価） | 6.62 | 2.54 | 最終モデルは6月も学習に使っているため楽観側 |
| 学習期間全体で測定 | 5.07 | 1.85 | 標本内。実力ではない |

引継ぎ報告値をそのまま出すと、特に **GL で 26% 楽観的**になります（2.54 → 実力 3.20）。
このため v4.3 で表示・判定の基準を時系列検証値へ切り替えました。

表示している最悪月（GI 6.9 / GL 4.2）は Mar/Apr/May の3フォールドの値ですが、
**6月を4つ目のフォールドとして追加しても最悪月は変わりません**
（6月は GI 6.82 / GL 2.69 で、むしろ良い月。最悪はいずれも3月）。

### 物理モデルの実力（v4.4.7 で測り直し）

`tools/evaluate_physics_model.py` で、GI の実機コイルと突き合わせて測れるようにしました。

実績データには **ノズルすき間** と **ノズル先端〜鋼板の真の距離** の記録がありません。
そこで `Z = 設備Y座標 + オフセット` とおき、オフセットとすき間を**学習期間だけ**で当てはめ、
後の期間で評価します。この2つはモデルの当てはめ値であって、**設備の実測値ではありません**。

```
GI 7,076コイル → 学習 4,527 / 評価 1,500（2026-05〜07）
当てはめ: Y座標オフセット −2.0 mm ・ すき間 1.4 mm
評価期間 MAE 7.21 g/m²（片面）＝ 14.4 g/m²（両面合計）
```

| | 両面合計 MAE |
|---|---:|
| 実績モデル（GI） | **6.7** |
| 理論モデル（GI・上記の当てはめ後） | **14.4** |

**理論モデルの誤差は実績モデルの約2.1倍**です。GI の条件決めには実績モデルを使ってください。
理論モデルは、実績に無い条件（ガス種・すき間の変更など）を検討するためのものです。

GL は浴温約600℃で物理モデルの前提から外れるため、評価していません。

#### 実績校正を掛けると 32% 改善する

**「実績校正」タブの6係数当てはめが、理論モデルの精度をいちばん上げます。**

| | 両面 MAE | P90 |
|---|---:|---:|
| 校正なし（出荷状態） | 14.4 | 13.4 |
| **実績校正あり** | **9.8** | 10.1 |

学習に使っていない期間で評価した値で、抽出を変えても再現します。
校正後も物理的な向き（圧力↑→付着量↓ など）は保たれます。

読み込ませるCSVは次で作れます。

```bash
python tools/evaluate_physics_model.py --export out/gi_calibration.csv --rows 500
```

**出荷時の既定値には入れていません。** この係数はこのラインのGIに、
当てはめたすき間・オフセットという前提ごと合わせたもので、前提が変われば合わなくなるためです
（`scale_factor` は探索範囲の上限に張り付いており、個々の係数に物理的な意味はありません）。

### 平均誤差の使い方（重要）

**MAE は個々の予測の信頼区間ではありません。** 「差が MAE より小さいから変えなくてよい」
とは言えません。このアプリが言えるのは **「モデルがその差を判別できるかどうか」** までで、
変える／変えないの判断は利用者に残しています。

| 目標との差 | 画面の言い方 |
|---|---|
| MAE 以下 | モデルはこの大きさの差を判別できません。実機で差が出るかは判断できません |
| MAE 〜 90%点 | 差の向きは参考になります。値は幅を持って読んでください |
| 90%点より大 | 条件を見直す根拠になる差です |

### 機械学習は「記号別中央値」より良いのか

「付着量記号を選んだら、その記号の実績中央値を出す」だけの単純なやり方と比べて、
モデルがどれだけ上乗せしているかを、4フォールドのローリング検証で測りました
（`tools/rolling_validation.py`）。中央値ベースラインは学習設定に依存しないので、
引継ぎ側のローリングCV値と直接比較できます。

| ライン | 記号別中央値のみ | 配布モデル相当 | 改善 |
|---|---:|---:|---:|
| GI | 7.40 | **6.72** | **−0.69 g/m²（9.3%）** |
| GL | 3.29 | **3.20** | −0.09 g/m²（2.7%） |

**GIではモデルに意味があります。GLではほとんどありません。**

GL を同一条件で4フォールド比較すると、改善は平均 −0.002 g/m²（ほぼゼロ）で、
月ごとの符号も +0.41 / −0.46 / −0.01 / +0.05 と定まりません。
**GLの予測は実質「付着量記号ごとの実績中央値」とみなすのが安全です。**
GL で通板速度・ノズル圧力を変更提案に使わないのも同じ理由です。

### 誤差が大きくなるコイル

アウトオブフォールド予測の誤差を、コイルの属性で切り分けました
（`tools/error_factors.py`）。

| 条件 | GI | GL |
|---|---|---|
| **付着量記号が前のコイルから変わった直後** | 平均\|誤差\| 9.22 vs 7.36（**1.25倍**） | 6.95 vs 3.14（**2.21倍**） |
| 通板時間が短い（下位25%） | 9.27 vs 7.15（1.30倍） | 逆に小さい（交絡の疑い） |
| 直前から操業条件が変わった | 有意差なし | 4.01 vs 3.09（1.30倍） |

**記号の切替直後は、両ラインとも明確に誤差が大きくなります**（いずれも p<0.0001）。
条件を記録した時刻と実際にワイピングされた位置の搬送遅れ、
および切替過渡が代表値に混じることが原因と考えられます。

これを受けて、手順1に **「直前のコイル：同じ記号／記号が変わる」** の切替を用意しました。
「記号が変わる」を選ぶと、**参考誤差と判定しきい値が実測倍率だけ広がります**
（GI 6.7→8.4、GL 3.2→7.1 g/m²）。**予測値そのものは変わりません。**

なお搬送遅れそのものの補正はできません。データが1コイル1行の代表値で、
コイル内の時系列が無いため、時間方向にずらす対象が存在しないためです。

## 装置画面（v4.1で追加）

実機のYG装置監視画面と同じ並びで、条件と予測を確認できます。値はすべて
**操業実績と予測モデルから再現**したもので、実機から直接読んでいるわけではありません。

各値には出所を必ず添えます。

| バッジ | 意味 |
|---|---|
| `実績` | 実績データから取得 |
| `予測` | 実績モデルの出力 |
| `導出` | 実績値から算術的に計算（平均とWS-DS差からWS/DS側を復元） |
| `未取得` | 該当する記録が無く再現できない |
| `未確認` | 実機画面との対応が未確定。同義扱いしていない |

**記録が無い項目**（ワイピング圧力・Yコンプレッサー吐出圧力・放風弁MV・
No.3Y機周波数・サポートロール回転・制御モード11種・指令No./コイルNo.）は、
枠だけ表示して「未取得」とし、推測値は入れていません。診断値も同様に、
計算に必要な値が無い項目は0で埋めず「未取得」と表示します。

制御モードは記録がないため全て `UNKNOWN` です。バッフルテスト・
ノズルクイックオープン・ノズル清掃中はアプリ側で検知できないため、
これらの作業中は結果を使わないでください。

## 2つのモードをつなぐ ── モデル比較タブ（v4.4で独立）

**「モデル比較」タブ**でボタンを1つ押すと、実績モデルの条件を理論モデルへ写して両方を計算し、
答えを並べます。実績モデル側・理論モデル側の**どちらのメニューからも開けます**
（v4.3 までは理論モデルの条件設計タブの下部に隠れていました）。

写すのは両モードで意味が同じ4項目（通板速度・板幅・浴温・目標付着量）だけです。

| 条件 | 実績モデル | 理論モデル | 扱い |
|---|---|---|---|
| 通板速度・板幅 | 中央速度・製品板幅 | 通板速度・板幅 | そのまま写す |
| 目標付着量 | 両面合計 | 片面 | **2で割って写す** |
| 浴温 | 使用ポット温度 | 浴温 | GIのみ写す。**GLは写さない**（約600℃は物理モデルの前提 420〜500℃ の外） |
| ノズル位置 | 設備Y座標 | ノズル先端〜鋼板の実距離 | **基準が違う。写さず差も取らない** |
| ノズル圧力 | 表ノズル圧力 | ノズル内部圧（大気圧との差） | **測定点が同じか確認できていない。写さず差も取らない**（v4.4で差の表示を取りやめ） |
| ノズルすき間・ガス種 | データに無い | 必須入力 | 理論側の仮定のまま |
| 付着量記号・製品区分・設備5項目 | 必須入力 | 概念が無い | 理論モデルは製品仕様を見ない |

付着量の差が **両モデルの誤差を足した幅**の内側かどうかで判定し、内側でも
「一致の証明にはならない」と明示します。あわせて、**両面合計の作り方が違う**ことも表示します
（理論モデルは片面×2の対称仮定、実績モデルは CF と CG の独立予測の和）。

## 何がどれだけ効くか（実データによる偏効果）

付着量記号の違いを打ち消して求めた、条件1単位あたりの効き目です。使い方タブに常時表示します。

| ライン | 項目 | 1単位あたり | 実績の振れ幅ぜんぶで |
|---|---|---:|---:|
| GI | Yノズル位置（表） | +2.05 g/m²/mm | 15.0 g/m² |
| GI | 通板速度 | +0.238 g/m²/(m/min) | 10.9 g/m² |
| GI | 製品板厚 | −13.8 g/m²/mm | 10.4 g/m² |
| GI | ノズル圧力（表） | −0.846 g/m²/kPa | 7.3 g/m² |
| GI | **ポット温度** | **−0.249 g/m²/℃** | **2.6 g/m²** |
| GI | 2JC進入板温 | +0.065 g/m²/℃ | 1.8 g/m² |
| GL | Yノズル位置（裏） | +1.09 g/m²/mm | 7.5 g/m² |
| GL | ポット温度 | — | 0.2 g/m²（特定不能） |

**浴温は GI で明確に効きます**（熱いほど亜鉛の粘度が下がり、持ち上げる膜が薄くなる＝付着量が減る）。
GLは実績のポット温度が 602〜603 ℃ とほぼ一定で、効果をデータから分離できません。
2JC進入板温はどちらのラインでも 1 g/m² 前後で、平均誤差より小さい影響です。

これらはすべて **v4.0 時点からモデルの入力に含まれています**。v4.2 では画面に効き目を表示し、
ポット温度と2JC進入板温を手順3へ移して見えるようにしました。

### 使っていない列について

ProC 228列すべて（数値として扱える185列）を、付着量記号内で中心化したうえで
CHとの相関・既存入力で説明した後の残差相関でふるいにかけました。
**上流工程に、追加すべき予測因子は残っていません。**

残差相関が高く出た列（GI: 2Coater APR周速 −0.14、CPC偏差 −0.14、TL シフト位置 +0.13 など）は
いずれも**ワイピングより下流の設備**で、付着量の原因にはなり得ません。
炉温・雰囲気ガス温度などの上流条件はいずれも残差相関 |r| < 0.10 でした。

## モデルの限界（実データ検証で判明したこと）

実データ（記号内で中心化した多変量回帰）とモデルの偏効果を突き合わせた結果です。

| ライン | 項目 | 実績全幅での効果 | 扱い |
|---|---|---:|---|
| GI | Yノズル位置 | 25.3 g/m² | 変更提案に使う |
| GI | ノズル圧力 | 14.3 g/m² | 変更提案に使う |
| GI | 通板速度 | 10.9 g/m² | 変更提案に使う |
| GL | Yノズル位置 | 10.6 g/m² | 変更提案に使う |
| GL | 通板速度 | 1.0 g/m² | **使わない**（効果を特定できない） |
| GL | ノズル圧力 | 0.9 g/m² | **使わない**（効果を特定できない） |

**GLは圧力・速度の実績レンジが狭すぎて**（圧力 9.9〜14.4 kPa）、めっき付着量への効果を
データから分離できません。この2項目は変更提案の対象から外し、理由を画面に表示します。

なお、通板速度の生の相関は負（GI −0.29）ですが、これは交絡です。他条件を揃えた偏効果は
**+0.24 g/m²/(m/min)**（速度が上がると持ち出しが増えて付着量は増える）で、
物理とモデルの向きは一致しています。

### 安全側に働く3つのガード

1. **判別できない差と、操業判断を分けて出す**  
   予測と目標の差が MAE（GI 6.7 / GL 3.2 g/m²）以内のときは
   「モデルはこの大きさの差を判別できません」と述べます。
   **「変更不要」とは言いません**（MAE は個々の予測の信頼区間ではないため）。
   そのうえで、判別できない差を埋めるために実績範囲の外へ出る提案になる場合は、
   **操業上の判断として**推奨しない旨を別枠で示します。
   これを入れる前は、GL/AZM100 で 1.7 g/m² の差を埋めるために
   Yノズル位置を 11.5 mm も動かす（実績範囲外）提案が無条件で出ていました。
2. **実データと逆向きの外挿はしない**  
   学習範囲の端は事例が乏しく、傾きが実データと逆に出ることがあります
   （例: GI/Z08 の薄板では Y>20 mm の実績が無く、モデル応答が微減する）。
   実データの偏効果と符号が合わない場合は延長せず、境界の値で止めます。
3. **実績範囲外は必ず明示**  
   範囲外の入力は案分で計算しますが、「実績範囲外」「境界の傾きを延長した参考値」と表示します。

## 重要な用語と注意

- **CH は両面合計**（表面3点平均＋裏面3点平均）。片面平均ではありません。
  付着量記号はこのCHに対応します（例: AZ150 → 実績中央値 161、Z08 → 94 g/m²）。
- **Yノズル位置は設備Y座標**で、鋼帯表面からの絶対距離ではありません。数値が大きいほど鋼帯から遠い側です。
- **ノズル吹込流量**は表裏合計の実測流量（Nm³/h・暫定定義）。圧力と強く連動（GI r=0.977 / GL r=0.933）するため、
  圧力を変えると実績の関係にそって流量も追従させています。
- **付着量記号305は対象外**。ラインスタート時のウォーマーコイルで製品ではないため、選択できません。
- **GLに理論モデルは使えません**。理由は浴温だけではありません。
  ①浴組成が Zn-55%Al-1.6%Si で、モデルの物性は純亜鉛系　②粘度・密度・表面張力の温度依存式が
  溶融亜鉛（420〜500℃）で当てはめたもので約600℃・高Alには外挿　③初晶Alデンドライトが広い温度幅で
  晶出するため「一定粘度の液膜が持ち上がる」という前提が成り立たない　④酸化被膜の性状が異なる。
- 実績件数が少ない付着量記号（20件未満）では警告を出します。予測も操業範囲も信頼度が下がります。
- 実績モデルは**過去実績の統計的補間**です。圧力・流量・Yノズル位置を独立に動かしたときの
  因果効果を保証するものではありません。

## 計算のしくみ

| | 実績モデル | 理論モデル |
|---|---|---|
| 原理 | 勾配ブースティング決定木（CatBoost） | 1次元薄膜方程式＋衝突噴流の実験相関 |
| 根拠 | 実機6か月・14,390件の実績 | 公開文献の相関式。実績データは不使用 |
| 逆算 | 41点走査＋24回の二分細分化 | 圧力・距離の2次元探索 |
| 主要式 | — | `Q(H)=H+SH²/2−GH³/3`、`H*=[S+√(S²+4G)]/2G` |
| 文献 | — | Thornton & Graff (1976) → Tuck (1983) → Ellen & Tu (1984) → Elsaadawy et al. (2007)／Gosset & Buchlin (2007) |
| 弱点 | 実績にない領域は当たらない。因果を保証しない | 幅方向の端部効果・ノズル固有形状・板のばたつきが入らない。GL適用外 |

使い方タブに、この内容を画面上でも説明しています。あわせて、公開文献・特許で報告されている
ワイピングの一般知見（圧力・ノズル距離の過大／過小で出る不良、エッジオーバーコート、
スプラッシュ、3スリットノズル、バッフルプレートなど）を出典リンク付きで載せています。

## 実績範囲の判定（v4.3で強化）

入力が実績のどこにいるかを、2段階で見ています。

1. **項目ごとのレンジ**（従来）… ライン全体の min〜max、付着量記号別の P01〜P99
2. **組合せとして実績にあるか**（v4.3で追加）… 付着量記号ごとに、
   板厚・板幅・Yノズル位置（表裏）・ノズル圧力・吹込流量・通板速度の7項目で
   実績分布からのマハラノビス距離を測り、実績の 90%点／99%点と比べます

2 が必要な理由は、**各項目が単独では実績内でも、その組合せが実績に無いことがある**からです。
例: GI/Z08 で板厚 1.6 mm は単独では実績内（P99）ですが、
薄目付記号でその板厚という組合せは実績にほぼ無く、距離 6.6（実績の99%は 5.7 以内）になります。
従来の判定では「実績範囲内」として素通りしていました。

判定は **要注意（caution）止まり**にしています。個々の値は実績内なので「範囲外」とは言えず、
探索を止めてしまうと正常な提案まで潰れるためです。

## 公開配布物に含まれる情報

このアプリは静的サイトなので、**配布した全ファイルは閲覧者が取得できます**。
公開する場合は、以下が外部から読めることを承知してください。

| ファイル | 含まれる情報 |
|---|---|
| `models/reference.json` | ライン別の生産本数、付着量記号別の操業レンジ（min/P01/P10/中央値/P90/P99/max）、規格・用途・類別などの区分と**それぞれの生産本数**、**生産仕様No.（GI 443件・GL 263件）とその本数** |
| `models/*.json` | 学習済みモデル本体（6ファイル・約1.8 MB） |
| `index.html` | 実機YG装置監視画面の項目名と並び |

配布方法をどうするかは運用側の判断です。参考として、件数と生産仕様No.を落とした
参照データを作るオプションを用意してあります（既定では動きません）。

```bash
python tools/build_reference_data.py "<入力フォルダ>" models --redact
```

このオプションを使った場合の**予測値への影響は実測で GI 0.000 / GL 平均 0.12・最大 0.54 g/m²**
で、モデル自身の誤差（GI 6.7 / GL 3.2 g/m²）より十分小さいことを確認しています。
数値レンジと記号別統計はアプリの動作に必要なため残ります。

## 実行方法

静的サイトです。ビルド不要。

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます（`file://` では fetch が失敗するため不可）。
初回のみ Pyodide と実績モデル（約1.9MB）のダウンロードに数十秒かかります。2回目以降はキャッシュされます。
