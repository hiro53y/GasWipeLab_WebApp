# GasWipeLab v3.0 — ワイピング条件 事前設定ツール

溶融亜鉛めっきライン（CGL）のガスワイピングについて、**実機を動かす前に操業条件を決める**ための
ブラウザアプリです。物理モデル（Python）を Pyodide でブラウザ内実行するため、サーバ不要・オフラインで動作します。

## 使い方（4タブ）

| タブ | いつ使うか | 入力 | 出力 |
|---|---|---|---|
| **条件設計** | 通常はこれだけでよい | ノズルすき間／通板速度／浴温／板幅／ガス種＋目標片面目付 | **噴射圧力**と**ノズル距離**。達成できない場合は変更提案 |
| **かんたん** | 速度もすき間も未定のとき | ガス種／板幅／目標片面目付 | 条件一式（すき間・速度・浴温・圧力・ノズル距離） |
| **検証** | 決めた条件の余裕を見るとき | 条件7項目 | 予測目付・リスク判定・応答カーブ・圧力×距離マップ |
| **実績校正** | 最初に一度やっておく | 実機実績CSV（8件以上） | 6係数の補正。以降の全計算に反映 |

### 目標が達成できないときの提案順

`通板速度` → `ノズルすき間` → `浴温` の順に、**1項目だけ**を現在値に最も近い値へ動かして
安全に達成できる値を探します。1項目で解決しない場合のみ `通板速度＋ノズルすき間` の同時変更を提案します。

**板幅とガス種は提案しません**（製品仕様・設備仕様のため）。

達成の判定には、スプラッシュ発生限界（Gosset–Buchlin の We/We*）に対して 15% の余裕を確保しています。

## 計算モデル

物理モデルは v2.2 から**変更していません**（精度に影響する式・係数はそのまま）。
v3.0 で追加したのは、既存 `AnalysisService.analyze()` を呼び出すだけの**探索レイヤ**です。

- ガス状態・ノズル出口流れ：等エントロピ圧縮性ノズル流れ
- 衝突噴流の壁面圧力・せん断：Elsaadawy et al. (2007) 近接場 ／ Ellen & Tu (1984) 遠方場、7<Z/d<9 は内挿
- 液膜：薄膜方程式の最大流束原理（Tuck 1983 / Ellen & Tu 1984）
- 目付：質量保存 `cw = ρ_L × h_f`
- スプラッシュ：Gosset & Buchlin (2007) の We/We* 判定
- 不確かさ・モデル信頼度：外挿要因ごとの加算評価

### 探索範囲（実操業レンジ。モデル有効域の内側）

| 項目 | 探索範囲 |
|---|---|
| 噴射圧力 | 5 〜 80 kPa |
| ノズル距離 | 6 〜 22 mm |
| 通板速度（提案時） | 40 〜 240 m/min |
| ノズルすき間（提案時） | 0.5 〜 2.5 mm |
| 浴温（提案時） | 450 〜 475 ℃ |

## 実行方法

静的サイトです。ビルド不要。

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます（`file://` では fetch が失敗するため不可）。
PWA としてホーム画面に追加できます。初回のみ Pyodide のダウンロードに 30 秒ほどかかります。

## 実績校正CSV

必須列（アプリ内の「記入用テンプレートCSVをダウンロード」で雛形を取得できます）:

```
plenum_pressure_kpa, nozzle_gap_mm, nozzle_strip_distance_mm,
line_speed_mpm, strip_width_mm, bath_temp_c, measured_cw_one_side_gm2
```

`gas_type`（air / nitrogen）は任意。8件以上かつ主要項目が3水準以上必要です。
校正結果は「保存」を押すまで適用されません。保存すると localStorage に残り、次回起動時も有効です。
